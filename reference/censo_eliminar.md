# Elimina la Base de Datos del Censo de tu Computador

Elimina el directorio `censo2017` y todos sus contenidos, incluyendo
versiones de la base de datos del Censo creadas con cualquier version de
'DuckDB'.

## Uso

``` r
censo_eliminar(preguntar = TRUE)
```

## Argumentos

- preguntar:

  Si acaso se despliega un menu para confirmar la accion de borrar
  cualquier base del censo existente. Por defecto es verdadero.

## Ejemplos

``` r
if (FALSE)  censo_eliminar()  # \dontrun{}
```
